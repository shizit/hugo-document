## Azure Stream Analytics

### 概要

Azure Stream Analyticsは、ストリーミングデータをリアルタイムに処理・分析するマネージドサービスです。

IoTデバイスやアプリケーションなどから継続的に送信されるデータを受け取り、フィルタリング、集計、条件判定などを実行できます。

### 構成例

```text
IoTデバイス
    ↓
  IoT Hub
    ↓
Stream Analytics
    ↓
分析・加工
    ↓
Azure SQL / Blob Storage / Power BI など
```

### 主な用途

* IoTセンサーから取得したデータのリアルタイム分析
* ストリーミングデータのフィルタリング
* データの集計
* 特定条件を満たすデータの検出
* リアルタイムダッシュボードへのデータ提供

### 特徴

SQLに似たクエリを使用して、ストリーミングデータの処理方法を定義できます。

例えば、温度センサーのデータに対して、80℃を超えるデータだけを抽出する、といった処理が可能です。

```sql
SELECT *
FROM input
WHERE Temperature > 80
```

### ポイント

Stream Analyticsは、データを蓄積してから処理するのではなく、**データが発生している途中でリアルタイムに処理する**ことを目的としたサービスです。

## Azure App Service

### 概要

Azure App Serviceは、WebアプリケーションやWeb APIをAzure上でホスティングするためのPaaSです。

.NET、Java、Node.js、Python、PHPなどのアプリケーションを実行できます。

### 構成例

```text
ユーザー
   ↓
インターネット
   ↓
Azure App Service
   ↓
Webアプリケーション / Web API
```

### 主な用途

* Webサイトの公開
* Web APIの公開
* Webアプリケーションのホスティング
* バックエンドアプリケーションの実行

### PaaSとしての特徴

App Serviceでは、仮想マシンやOSなどの実行基盤をAzureが管理します。

そのため、利用者はサーバーの構築やOSの保守を行うことなく、アプリケーションをデプロイして利用できます。

```text
利用者が管理
┌────────────────────┐
│ アプリケーション    │
└────────────────────┘
          ↓
      Azureが管理
┌────────────────────┐
│ OS / 実行基盤       │
│ ハードウェア        │
│ ネットワークなど    │
└────────────────────┘
```

### Azure Functionsとの違い

App ServiceとAzure FunctionsはどちらもアプリケーションをAzure上で実行できますが、主な用途が異なります。

|      | App Service        | Azure Functions |
| ---- | ------------------ | --------------- |
| 主な用途 | Webアプリ・Web API     | イベントに応じた処理      |
| 実行形態 | Webアプリケーションをホスティング | イベントをトリガーとして実行  |
| 主な特徴 | Webサービスの公開         | サーバーレス・イベント駆動   |

## Azure IoT Hub

### 概要

Azure IoT Hubは、IoTデバイスとAzureの間で通信を行うためのマネージドサービスです。

IoTデバイスからAzureへのデータ送信だけでなく、AzureからIoTデバイスへのコマンド送信にも利用できます。

### 構成例

```text
                 Azure
                   │
                   ↕
              ┌─────────┐
              │ IoT Hub │
              └─────────┘
                ↕  ↕  ↕
                │  │  │
             センサー カメラ 機器
```

### 主な用途

* IoTデバイスからのデータ収集
* IoTデバイスへのコマンド送信
* デバイスの認証・識別
* 大量のIoTデバイスとの通信
* IoTデバイスの管理

### データ収集の例

温度センサーから取得したデータをIoT Hubへ送信します。

```text
センサー
   ↓
温度：75℃
   ↓
IoT Hub
   ↓
Azure上の各種サービス
```

IoT Hubで受信したデータは、Stream Analyticsなどのサービスに渡して分析できます。

### 双方向通信

IoT Hubでは、デバイスからAzureへの通信だけでなく、Azureからデバイスへの通信も可能です。

```text
IoTデバイス ─────→ Azure
       ↑
       │
       └───────── Azureからの指示
```

例えば、Azure側から設備の停止や設定変更などの指示を送信できます。

### ポイント

IoT Hubは、IoTデバイスから送られてくるデータを単に保存するサービスではなく、**IoTデバイスとAzureを接続するための通信・管理基盤**として利用します。

## Azure Functions

### 概要

Azure Functionsは、イベントをトリガーとしてコードを実行するサーバーレスコンピューティングサービスです。

サーバーやOSなどの実行基盤を利用者が直接管理することなく、必要な処理を実行できます。

### 基本的な構成

```text
イベント
   ↓
Azure Functions
   ↓
コードを実行
   ↓
処理結果
```

### 主なトリガー

Azure Functionsでは、さまざまなイベントをきっかけとして処理を実行できます。

* HTTPリクエスト
* タイマー
* キューへのメッセージ追加
* Azure Storageのイベント
* IoT関連のイベント

### HTTPリクエストを利用した例

```text
クライアント
    ↓
HTTPリクエスト
    ↓
Azure Functions
    ↓
データ処理
    ↓
レスポンス
```

HTTPトリガーを使用することで、APIとしてFunctionsを利用することもできます。

### サーバーレス

サーバーレスは、サーバーが存在しないという意味ではなく、**サーバーやOSなどのインフラストラクチャをAzure側で管理する**という考え方です。

利用者は主に処理するコードを作成し、Azure Functions上で実行します。

### イベント駆動

Functionsでは、何らかのイベントが発生したことをきっかけとして処理を開始します。

例えば、

```text
ファイルがアップロードされる
        ↓
Azure Functionsが起動
        ↓
ファイルを処理
```

```text
キューにメッセージが追加される
        ↓
Azure Functionsが起動
        ↓
メッセージを処理
```

といった構成が可能です。

# 4つのサービスの関係

IoTシステムでは、4つのサービスを組み合わせて利用できます。

```text
┌──────────────┐
│ IoTデバイス  │
└──────┬───────┘
       │
       ↓
┌──────────────┐
│   IoT Hub    │
│ データ収集   │
└──────┬───────┘
       │
       ↓
┌──────────────────┐
│ Stream Analytics  │
│ リアルタイム分析  │
└────────┬─────────┘
         │
         ↓
    ┌─────────┐
    │ Functions│
    │ イベント処理│
    └─────────┘
```

例えば、工場の温度センサーを利用する場合、以下のような処理を構築できます。

1. センサーが温度データを取得
2. IoT Hubがデータを受信
3. Stream Analyticsがデータをリアルタイムに分析
4. 異常な温度を検出
5. Azure Functionsで通知などの処理を実行

さらに、分析結果をWeb画面から確認する場合は、App Serviceを組み合わせます。

```text
                      ┌──────────────┐
                      │Stream Analytics│
                      └──────┬───────┘
                             │
                             ↓
                        データ保存
                             │
                             ↓
┌──────────────┐      ┌──────────────┐
│ IoTデバイス  │ →    │    IoT Hub    │
└──────────────┘      └──────┬───────┘
                             │
                             ↓
                     ┌──────────────┐
                     │Azure Functions│
                     └──────────────┘

ユーザー
   ↓
App Service
   ↓
分析結果を表示
```

## サービスごとの役割

| サービス                   | 主な役割                       |
| ---------------------- | -------------------------- |
| Azure IoT Hub          | IoTデバイスとAzureの通信・管理        |
| Azure Stream Analytics | ストリーミングデータのリアルタイム処理・分析     |
| Azure Functions        | イベントをトリガーとしたコード実行          |
| Azure App Service      | Webアプリケーション・Web APIのホスティング |
